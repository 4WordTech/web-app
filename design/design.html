Usage

  • bg — page canvas, form fields, nested cards on surface
  • surface — footer, cards, section bands
  • elevated — CTA banners, hover lifts
  • ink — primary text, logo, nav hover
  • muted — body copy, labels, secondary links
  • accent — eyebrows, CTAs, focus rings, highlights

Derived / special

  • Primary hover: #d6ff62
  • Warm radial glow: #E4C9A5 at ~7–10% opacity
  • Selection: accent fill + accent-ink text
  • Error (forms): Tailwind text-red-400
  • Ink alphas: ink/85, ink/80, ink/70, ink/40, ink/35, ink/15, ink/5
  • Accent alphas: accent/40, accent/30, accent/10

07 · Motion

Motion & interaction

Motion library with a shared ease curve. Respects prefers-reduced-motion everywhere.

Reveal

opacity 0 → 1 · y 28 → 0

duration 0.8 · ease [0.22, 1, 0.36, 1]

  • Viewport once · margin -80px
  • Stagger via delay prop (0.06–0.15 steps)
  • Hero lines: y 110% mask reveal ~0.95s

Other motion

  • Header hide on scroll down (y > 80): translate -96px · 0.35s
  • Magnetic: spring stiffness 260 · damping 18
  • Logo float: 14s easeInOut y/rotate loop
  • Marquee: 28s linear infinite
  • Custom cursor springs (dot + ring)
  • CSS: scroll-behavior smooth (disabled when reduced)

Key files

  • src/app/globals.css — tokens, utilities, selection, reduced motion
  • src/app/layout.tsx — Geist, Syne, Instrument Serif, grain, chrome
  • src/components/ui.tsx — Button, Reveal, SectionHeader, Marquee, Magnetic, Badge
  • src/components/CustomCursor.tsx — cursor system
  • src/components/SiteHeader.tsx / SiteFooter.tsx — chrome
  • src/components/home/Hero.tsx — hero type + atmosphere recipe
  • src/components/CtaBanner.tsx — elevated CTA panel
  • src/components/ContactForm.tsx — form control styles
  • src/components/Logo.tsx — wordmark SVG

Do

  • Use display + serif contrast sparingly in headlines
  • Keep CTAs lime pills; secondary as quiet outline
  • Stick to the 1400px rail and 28px panel radius
  • Honor reduced-motion (skip springs / loops)

Don’t

  • Introduce purple / indigo gradient themes
  • Default to Inter / Roboto / system-only stacks
  • Add heavy multi-shadow card chrome
  • Crowd the hero with stats, chips, or promo stickers
